- **MOD-01..03 (Phase 3):** `src/routes/high-school/unit-circle/[[step]]/` is a route written for this concept only, and `ConceptManifest` is still provisional. The `ucStep` key in `app.d.ts` and the thumbnail wiring also need generalizing.

- **PLAY-07 (Phase 2):** `Player`, `restage` and `POLICY` have only one consumer, the unit-circle concept. A predict-then-reveal pause will be the first test of whether they work generically.
- **A11Y-02..04 (Phase 6):** keyboard and ARIA handling exists only in the unit-circle slice so far.
