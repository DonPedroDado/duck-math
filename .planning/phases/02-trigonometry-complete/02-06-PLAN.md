## Phase Goal

ROADMAP Phase 2 goal (verbatim): "A student can see every core trig idea geometrically, from tan and its friends through the unrolled sine/cosine graphs to identities and special angles." Success criterion 2: "Student can play or scrub the circle unrolling into sine and cosine graphs in a synced side-by-side panel, with the moving point leaving a fading trail."

<objective>
Build the shared stage pieces the trig concepts draw on. This plan has two parts. The first is pure, tested graph geometry: the two-panel layout, curve sampling, the literal peel (D-09), and the single-writer display rule. The second is three components: PanelPair (MATH-05), the shared CircleBase backdrop, and the ConceptLayout 'below' variant CSS. Plan 07 wires these into the "Sine & cosine graphs" concept (Scene, Panel, runtime, manifest). Tangent (Plan 05) and Identities (Plan 08) render CircleBase.

Purpose: this is Research Pattern 5 (one SVG with two coordinate frames, so the unroll and the connector cross panels trivially) and Pattern 6 (the unroll as a pure per-sample lerp that scrubs both ways). One deviation is noted: UI-SPEC said "two SVG panels", but research shows the cross-panel animation needs one SVG. The unroll lerps to the graph's x-scale because 2π·R does not fit in the 7/12 graph width. CONTEXT notes radian.ts as reusable; only its seg/E idiom is reused (Research A4).
Registration safety: this plan creates NO `index.ts`, `step-ids.ts` or `runtime.ts` in `sine-cosine-graphs/`. `conceptRoutes()` and the registry ignore the folder until Plan 07's final task, so the shared deeplink, catalog and mobile specs are not affected while this plan runs.
Output: panelpair.ts, graph.ts, unroll.ts, display.ts and notation.ts with tests; PanelPair.svelte; CircleBase.svelte; ConceptLayout `.below` CSS.
</objective>

Use row mode when W >= 640: size = W*5/12, H = size, cx = cy = size/2, R = size/3, x0 = size + 24, x1 = W - 16, axisY = cy, gR = R, top = 24, bottom = H - 24. Otherwise, for k = 0..n, it uses s = theta*k/n and returns lerp(onCircle(s), onAxis(s), unrollBlend(k, n, q)).
5. `display.ts`: `displayTheta(v: { sweepOn: number; rewind: number; sweep: number }, user: { theta: number; moved: boolean })` = moved || sweepOn === 0 ? user.theta : rewind < 1 ? user.theta * (1 - rewind) : sweep (per D-11: the timeline never writes θ). `fmtAngle(theta, unit, locale)`: for deg, round the unwrapped degrees d to 1 decimal and snap to the nearest integer within 0.05, then return `fmt(d, Number.isInteger(d) ? 0 : 1, locale) + '°'`.
