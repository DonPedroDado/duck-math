<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| URL -> route load | `concept` and `step` path params are attacker-controlled strings |
| Build -> static host | Prerender list decides which pages exist on the static host |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Tampering | `[concept]/[[step]]/+page.ts` | mitigate | `concept` matched only by exact equality against registry `path`; `step` only via `manifest.stepIds.includes`; anything else `error(404)`. No param is interpolated into HTML or import paths except the registry-derived `manifest.path`. |
| T-02-02 | Tampering | `runtimes.ts` loader | mitigate | Glob map keys are fixed at build time; `loadRuntime` only looks up a key, never builds a dynamic `import()` from user input. |
| T-02-03 | Tampering | `page.state.conceptStep` (history state) | mitigate | Effect acts only if `manifest.stepIds.includes(id)`; foreign/forged state is ignored. |
| T-02-04 | Denial of Service | prerender entries | mitigate | Entries derived from `conceptRoutes()`; e2e asserts build file exists for every concept x locale x step. |
| T-02-05 | Information Disclosure | static site | accept | Public content, no secrets, no accounts. |
</threat_model>
