## Formula lines (TeX; `N(x)` = `texNum(fmt(x, 2, locale))`, `D` = `texNum(fmtDeg(theta, locale).replace('°',''))`, `C/S` = derive(θ).cos/sin)
| Step | Lines |
|------|-------|
| intro | `[]` |
| angle | `\htmlClass{t-angle}{\theta} = \htmlClass{t-angle}{D^\circ}` |
| radian | `\htmlClass{t-radian}{1\ \mathrm{rad}}` |
| radians (unit rad) | θ untouched default (`Math.abs(theta - Math.PI/3) < 1e-9`): `\htmlClass{t-angle}{\theta} = \htmlClass{t-angle}{\tfrac{\pi}{3}} \approx \htmlClass{t-angle}{R}`; otherwise `\htmlClass{t-angle}{\theta} \approx \htmlClass{t-angle}{R}`, where `R = texNum(fmtRad(theta, locale))` |
| radians/cosine/sine (unit deg) | first line is the angle-step line instead of the rad line (radians step only) |
| cosine | `\htmlClass{t-cos}{\cos\theta} = x = \htmlClass{t-cos}{N(C)}` |
| sine | `\htmlClass{t-cos}{\cos\theta} = \htmlClass{t-cos}{N(C)}`, `\htmlClass{t-sin}{\sin\theta} = \htmlClass{t-sin}{N(S)}`, `P = (\htmlClass{t-cos}{\cos\theta}SEP\htmlClass{t-sin}{\sin\theta})` with `SEP = locale === 'de' ? '\,;\,' : ',\ '` (German decimal comma makes `,` ambiguous as a tuple separator) |
No `\text{...}` with words (formulas carry no language). sin/cos stay sin/cos in both locales (I18N-03).
