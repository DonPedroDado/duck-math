## Player semantics (PD-2) — implement and test exactly
| Action | Result |
|--------|--------|
| initialState(steps, i=0) | `{ t: stepEnd(i), step: i, playing: false, rate: 1 }` |
| play, or toggle while paused | if `t < stepEnd(step) − 1e-9` -> `playing: true` (resume same step). Else if `step < last` -> `step+1, t = stepStart(step+1), playing: true`. Else (last step staged) -> `step 0, t 0, playing: true` (restart) |
| toggle while playing, pause | `playing: false` |
| tick(dt) | not playing -> same object. Else `t = min(t + clamp(dt, 0, MAX_DT) * rate, stepEnd(step))`; if `t >= stepEnd(step)` -> `playing: false` (never crosses into the next step) |
| next | `step < last` -> `step+1, t = stepStart(step+1), playing: true`; last -> same object |
| prev | `step > 0` -> `step−1, t = stepEnd(step−1), playing: false`; step 0 -> `t = stepEnd(0), playing: false` |
| reset | `step 0, t = stepEnd(0), playing: false` |
| seek(t) | `playing: false, t = clamp(t, 0, total), step = locate(t).i` |
| goto(i) | `step = clamp(i, 0, last), t = stepEnd(step), playing: false` |

The layer schedule (which `UCView` field rises when) is implemented and tested in `view.ts` (01-04); this plan only renders `v.*` values.
