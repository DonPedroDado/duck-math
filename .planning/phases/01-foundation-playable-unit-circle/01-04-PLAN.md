## Plan-time decisions (LOCKED by the user; override UI-SPEC where they conflict)
- **PD-1:** Step `angle` does NOT sweep the point. The point stays at its current θ (default 60°); only the arc and θ label draw on from 0 to θ. The timeline never writes θ. (`view()` returns no θ; θ has exactly one writer: the student.)

- **PD-3:** The `radian` animation always lays radius copies up to π, independent of θ (implemented in plan 01-09; this plan only exposes the radian step's local progress).

## Step durations (seconds; UI-SPEC defaults) and view schedule
`STEPS = [intro 2.0, angle 2.5, radian 4.0, radians 2.0, cosine 2.5, sine 2.5]`, total 15.5 s. Ends: 2.0, 4.5, 8.5, 10.5, 13.0, 15.5.

Rule for every layer value L introduced in step k with in-step schedule f_k(p): `L = i > k ? 1 : i < k ? 0 : f_k(p)` where `{i, p} = locate(STEPS, t)`. `E = easeMath`.

| Field | Step k | f_k(p) |
|-------|--------|--------|
| axes | intro | E(seg(p, 0, 0.2)) |
| circle | intro | E(seg(p, 0.2, 0.6)) |
| point | intro | E(seg(p, 0.6, 0.8)) |
| hint | intro / angle | intro: seg(p, 0.8, 1); angle: 1 − seg(p, 0, 0.1); later steps 0 |
| arc | angle | E(seg(p, 0, 0.6)) |
| thetaLabel | angle | E(seg(p, 0.5, 0.8)) |
| readout | angle | E(seg(p, 0.6, 0.9)) |
| radian | radian | p (raw; plan 01-09 applies its own phases) |
| oneRadLabel | radian | E(seg(p, 0.42, 0.52)) |
| piLabel | radian | E(seg(p, 0.93, 1)) |
| copiesDim | radians | E(seg(p, 0.2, 0.6)) |
| toggle | radians | E(seg(p, 0, 0.15)) |
| unitBlend | radians | special: `user.unit === 'deg' ? 0 : i < 3 ? 0 : i === 3 ? E(seg(p, 0, 0.4)) : 1` |
| cosDrop | cosine | E(seg(p, 0, 0.16)) |
| cosSeg | cosine | E(seg(p, 0.16, 0.48)) |
| cosLabel | cosine | E(seg(p, 0.48, 0.64)) |
| sinDrop | sine | E(seg(p, 0, 0.16)) |
| sinSeg | sine | E(seg(p, 0.16, 0.48)) |
| sinLabel | sine | E(seg(p, 0.48, 0.64)) |

Every schedule reaches its final value by p = 1 and starts at 0 for p = 0, so `view` is continuous across step boundaries (tested).

## Player semantics (PD-2) — implement and test exactly
| Action | Result |
|--------|--------|
| initialState(steps, i=0) | `{ t: stepEnd(i), step: i, playing: false, rate: 1 }` |
| play, or toggle while paused | if `t < stepEnd(step) − 1e-9` -> `playing: true` (resume same step). Else if `step < last` -> `step+1, t = stepStart(step+1), playing: true`. Else (last step staged) -> `step 0, t 0, playing: true` (restart) |
| toggle while playing, pause | `playing: false` |
| tick(dt) | not playing -> same object. Else `t = min(t + clamp(dt, 0, MAX_DT) * rate, stepEnd(step))`; if `t >= stepEnd(step)` -> `playing: false` (never crosses into the next step) |
| next | `step < last` -> `step+1, t = stepStart(step+1), playing: true`; last -> same object |
| prev | `step > 0` -> `step−1, t = stepEnd(step−1), playing: false`; step 0 -> `t = stepEnd(0), playing: false` |
| reset | `step 0, t = stepEnd(0), playing: false` |
| seek(t) | `playing: false, t = clamp(t, 0, total), step = locate(t).i` |
| goto(i) | `step = clamp(i, 0, last), t = stepEnd(step), playing: false` |
