| Token | Value |
|-------|-------|

## Typography

Exactly 4 sizes and 2 weights.

| Role | Size | Weight | Line Height | Used for |
|------|------|--------|-------------|----------|
| Body | 16px | 400 | 1.5 | Captions, catalog hooks, readout labels |
| Label | 14px | 600 | 1.4 | Buttons, toggle, step counter ("Step 3 of 6"), badges ("Soon"), axis tick labels, scrubber time labels |
| Heading | 20px | 600 | 1.2 | Wordmark, section headings (category), card titles, side-panel concept title; KaTeX formulas render at 20px |
| Display | 28px | 600 | 1.2 | Catalog page title only; concept page `h1` on desktop (24px not allowed; phone uses Heading 20px) |

Rules:
- Weights are 400 and 600 only. KaTeX uses its own fonts at its native weights inside formulas; this does not count as a UI weight.
- Numeric readouts use `font-variant-numeric: tabular-nums` so values do not jitter while dragging.
- Stage SVG text labels (theta, sin, cos, "1 rad", ticks) use Label 14px (600), never below 14px in rendered pixels: SVG text is sized in CSS px against a counter-scaled `font-size`, not viewBox units.
- Uppercase and letter-spacing are not used (German strings are long).
- German tolerance: no fixed-width containers for text. Buttons use `min-width` + padding; captions wrap freely; side panel allows 3 more lines of caption than EN; test with the longest DE string (see Copywriting).

## Layout Contract

### Global shell
- Header (56px, `--surface`, bottom border `--border`): left wordmark "Duck Math" (links to `/{locale}/`), right language switcher (EN | DE). On the concept page the header also shows a back link "Catalog" (chevron-left icon + text) after the wordmark on tablet/desktop; on phone it replaces the wordmark with a 44px back button + concept title (Label 14px).
- Max content width for catalog: 1120px, centered, side padding md (16px) phone / lg (24px) tablet+.
- Language switcher: two 44x44 segmented buttons "EN" / "DE" (Label), `aria-current="true"` on active, navigates to the same route in the other locale (keeps step), stores choice in `localStorage` key `dm-locale` (D-16). Keeps `lang` attribute on `<html>` in sync.

### Catalog page (`/{locale}/`) — SHELL-01, SHELL-02, D-15
- Page title Display 28px: EN "Visual math" / DE "Mathe sehen" (default). Below it, one Body line (max 1 sentence).
- Section "High School" (Heading 20px) then a card grid: CSS grid `repeat(auto-fill, minmax(256px, 1fr))`, gap xl (32px) desktop, md (16px) phone.
- Card (`--surface`, 1px `--border`, radius 12px, padding md): top = static SVG thumbnail 16:9 (`--bg` fill, thumbnail art uses semantic palette, e.g. unit circle with cos/sin segments), then title (Heading 20px), then one-line hook (Body 16px, `--text`, clamp to 2 lines).
- Live card (Trig / Unit circle): an `<a>`, hover: border becomes `--axis`, thumbnail glow `--glow-sm`, translateY(-2px) over `--dur-ui`. Whole card clickable, min 44px target trivially met.
- "Soon" cards (Functions, Limits, Derivatives): not links (`<div>`, `aria-disabled="true"`), opacity 0.5 on content, a "Soon" badge (Label 14px, `--surface-raised` pill, radius 999px, padding 4px 8px) top-right of the thumbnail. No hover effect, no pointer cursor.
- Section "University" (Heading 20px, `--text-muted`): a single full-width dimmed placeholder card with text "Coming later" (no thumbnail). Dimmed to 0.5 opacity. Spacing between sections 2xl (48px).
- Page bottom padding 3xl (64px).

### Concept page (`/{locale}/high-school/unit-circle/{step}`) — D-05, D-06

Breakpoints: phone `< 640px`, tablet `640-1023px`, desktop `>= 1024px`.

**Desktop (>= 1024px)**
- Below header, a CSS grid with two columns `minmax(0, 62fr) minmax(320px, 38fr)`, column gap lg (24px), padding lg (24px). Rows fill `100dvh - 56px - 72px`.
- Left: stage, a square (`aspect-ratio: 1`), sized `min(100%, 100dvh - 56px - 72px - 48px)`, background `--bg` with 1px `--border`, radius 12px, centered in column. `touch-action: none` on the stage SVG.
- Right: side panel (`--surface`, radius 12px, padding lg, overflow-y auto, `gap: 24px` column flex) containing in order: (1) step counter "Step 3 of 6" (Label, `--text-muted`) , (2) concept title (Heading 20px; Display 28px as `h1` is used only for the title at top of panel on desktop), (3) caption (Body 16px, `aria-live="polite"`, min-height 4 lines to avoid layout jump when steps change), (4) formula block, (5) deg/rad toggle (only visible from step 4, and reserved space beforehand so layout never shifts; in steps 1-3 area shows nothing but keeps height).
- Bottom: player bar full width, 72px, `--surface`, top border `--border`, content centered with max width 960px.

**Tablet (640-1023px)**: same stacked order as phone, but stage max-width 560px centered, player bar not sticky-to-viewport only if content fits (still sticky bottom).

**Phone (< 640px)** (D-06, A11Y-01)
- Vertical stack: header 56px; stage full width square (`width: 100vw`, `aspect-ratio: 1`, no side margin, no radius); then a scrollable content area (padding md) with step counter, caption, formula, toggle; player bar `position: sticky; bottom: 0` (64px + `env(safe-area-inset-bottom)`), `--surface`, top border `--border`.
- The stage is `position: sticky; top: 56px` so the visual never scrolls away while the panel text scrolls beneath it (when content is taller than the viewport). Stage SVG has `touch-action: none` so dragging the point never scrolls the page (D-06). The rest of the page keeps native scrolling.
- No horizontal overflow at 320px width in EN or DE. The player bar controls shrink the scrubber, never the 44px buttons.
- Viewport meta: `width=device-width, initial-scale=1, viewport-fit=cover`.

### Player bar (all sizes) — PLAY-01, PLAY-02, D-07, D-08, D-09
Left to right: [Reset 44px] [Prev step 44px] [Play/Pause 48px, accent fill, 24px icon, radius 999px] [Next step 44px] [scrubber flexible]. Gap sm (8px) between buttons, md (16px) before the scrubber. On phone the same order, scrubber on the same row (min width 96px; if narrower than 360px viewport it wraps below, never overlaps).

- Buttons: transparent background, icon `--text`; hover `--surface-raised`; pressed scale 0.96; disabled opacity 0.4 (Prev disabled at step 1 at t=0, Next disabled on last step end, Reset disabled when already at start).
- Each button has `aria-label` from messages and a native `title` tooltip; Play/Pause label toggles.
- Scrubber: single continuous bar across all six steps (D-07). Track 4px high `--border`, filled portion `--accent`, 16px circular knob (`--accent`, 2px `--bg` ring), hit area 44px. Six step segments are equal width; 5 interior tick marks plus the start at step boundaries (2px x 12px, `--axis`; the tick of the current step is `--text-strong`). Clicking/tapping a tick jumps to the start of that step (staged state, not auto-playing). Dragging the knob scrubs the timeline continuously in both directions; pointer capture used; `role="slider"` with `aria-valuemin=0`, `aria-valuemax=100`, `aria-valuetext` = "Step 3 of 6: {step title}". (Full keyboard operation is Phase 6, but native focusability and arrow-key handling on the slider is cheap and should be included.)
- Step titles appear in a small tooltip above a tick on hover/long-press (Label 14px on `--surface-raised`).

## Interaction Contract

### Player state machine (D-02, D-08, D-09, PLAY-01, PLAY-05)
- Initial state: step 1 (`intro`) or the deep-linked step, **paused, staged, no autoplay**. Stage shows the final staged state of the step (animation already "complete") with a prominent accent Play button (pulse ring once, 1.2s, 1 repetition, then static; disabled when reduced motion).
- Play: runs the current step's animation (about 2-4 s), then **stops at the end of the step** and icon returns to Play. Pressing Play again (or Next) runs the next step's animation. At the last step end, Play becomes Reset-like: pressing Play restarts from step 1.
- Next: jumps to the next step and plays its animation immediately, then stops. Prev: jumps to the previous step's staged end state without animation (replay with Play). Reset: to step 1 at t=0, staged.
- Scrub: the visual is a pure function of (timeline time, user params). Scrubbing back to any time shows exactly the right visual; scrubbing back through the radian peel-off must unwind it (D-04).
- Step change updates: URL (see below), step counter, caption (cross-fade 150ms; none if reduced motion), formula, scrubber.

### Drag (PLAY-04, PLAY-05, PLAY-06, D-02, D-03)
- The point is draggable at every step, including during animation. Drag uses pointer events with pointer capture, works with mouse and touch, 60fps; the point follows the pointer's angle (atan2 around the origin), clamped to the circle (radius 1, the point cannot leave the circle).
- Dragging while an animation is playing: animation **pauses immediately** at its current frame; the point tracks the pointer without any jump (the first frame of the drag reads the pointer position, never the timeline value). On release the player stays paused (the Play button shows Play); pressing Play resumes from the paused point, and any param the student changed stays where the student set it (timeline only writes params it owns for this step: ownership model `timeline`/`user`).
- The student's dragged angle persists across steps (D-03). Layers/visibility are re-staged per step. A step animates the point to a specific angle only when it needs one: only `angle` (step 2) sweeps to a demo angle if the student has not moved the point yet (otherwise keeps their angle); `radian` and `radians` use the current angle; no other step moves the point.
- Default starting angle (default): 60 degrees (pi/3), so step 4's "pi/3" matches without moving. If the student has moved the point, step 4 formula shows their angle instead; the caption wording must stay generic (no hard-coded "60").
- Cursor: `grab` over the point, `grabbing` while dragging. Hover on point: halo grows from 20px to 36px over `--dur-ui` with `--glow-md`; while dragging the halo stays at 36px with 25% opacity fill of `--c-point`. A "drag me" hint (Label 14px, `--text-muted`, with a small curved arrow) appears next to the point in step `intro` only until the first drag, then fades out and never returns this session.
- Angle snap: none in Phase 1 (snapping is Phase 2). Angle wraps in [0, 360). Dragging through 0 wraps smoothly with no jump in the displayed value other than 359.9 to 0.0.

### Deep links (SHELL-03, D-17)
- Pattern: `/{locale}/high-school/unit-circle/{stepId}`; step IDs: `intro`, `angle`, `radian`, `radians`, `cosine`, `sine`. Concept base URL without step opens `intro`. Changing steps uses `history.replaceState`/`pushState` (push on user step changes, replace during scrubbing) without scroll reset and without a full navigation. Unknown step ID shows the 404 state.

### Deg/rad toggle (TRIG-01, D-01 step 4)
- Segmented toggle with two options "deg" and "rad" (Label 14px, 44px high, track `--surface-raised`, active option `--bg` fill with `--text-strong`; the active option is not accent-colored). Introduced at step `radians` with a 300ms slide-in; stays through steps 5-6. In steps 1-3 the readout is degrees; step 3 also shows "1 rad". Default unit at step 4 and later: radians; in steps 1-2 degrees (default). Switching the toggle changes the readout, the arc label and the formula's theta value immediately; no animation on the value besides a 150ms cross-fade.

### Readouts and formulas (MATH-01, MATH-02, I18N-03)
- Formula block (inside side panel/under the stage on phone), KaTeX rendered at build time (SSR) with `trust` enabled only for `\htmlClass`. Terms colored by class: `\htmlClass{t-cos}{\cos\theta}` mapped to `--c-cos`, etc. Formulas shown per step:
  - `angle`: `\theta = 60^\circ` (theta in `--c-angle`)
  - `radian`: `1\ \text{rad}` in `--c-radian` (no `\text` words in KaTeX: unit symbol "rad" is language-neutral)
  - `radians`: `\theta = \frac{\pi}{3} \approx 1{,}05` (locale decimal separator via formatter; in EN `1.05`)
  - `cosine`: `\cos\theta = x = 0{,}50`
  - `sine`: both lines: `\cos\theta = 0{,}50` and `\sin\theta = 0{,}87`, plus `(\cos\theta,\ \sin\theta)` for the point
- Readout values update live while dragging (each frame), 2 decimals (default) for cos/sin, 1 decimal for degrees ("60.0 degrees" shown as `60°`: integer when the value is within 0.05 of an integer, otherwise 1 decimal), 2 decimals for radians. Numbers use the locale formatter (`Intl.NumberFormat`): `0,87` in DE, `0.87` in EN. Negative numbers use a true minus sign U+2212.
- Function names sin, cos remain `sin`/`cos` in both locales.
- Formula block min-height reserves 2 lines (about 96px) so the side panel does not reflow between steps.

### Step animations (D-01, D-02, D-04, D-12) — durations are defaults; ease `--ease-math`

| Step ID | Animation on entry | Duration | Staged end state |
|---------|--------------------|----------|-------------------|
| `intro` | Axes fade in (400ms), circle draws on (800ms, from 0 degrees counter-clockwise), point scales in 0 to 1 with halo pulse | 2.0s | Circle + axes + radius line + point at start angle; "drag me" hint |
| `angle` | Angle arc (radius 0.25 in unit coordinates) draws on from 0 to theta; theta label fades in; if point not yet moved, point sweeps from 0 to 60 degrees first | 2.5s | Arc + `theta` label + degrees readout |
| `radian` | A copy of the radius (length 1, `--c-radian`) peels off the x-axis end (rotates up 30 degrees off the axis), moves to the edge of the circle, bends (interpolated from straight segment to arc of length 1) onto the circle starting at angle 0; repeats whole copies up to about 3.14 (3 full copies plus a 0.14 remainder, copy count `floor(theta_in_rad)` capped at pi so it reaches pi); a bracket label "1 rad" appears at the first copy | 4.0s | Radius copies laid along the arc up to the current angle; final fractional copy proportional |
| `radians` | Degrees label morphs (cross-fade) into radians label; deg/rad toggle slides in; the copies fade to a subtle 40% opacity | 2.0s | Toggle visible, readout in rad, theta = pi/3 formula |
| `cosine` | Vertical dashed projection from the point to the x-axis draws on (400ms), then the cos segment (origin to foot of projection, `--c-cos`, 4px) draws on (800ms); label "cos" fades in; formula line appears | 2.5s | Dashed drop line + cos segment + label + formula + live readout |
| `sine` | Same pattern for sin: horizontal dashed projection to the y-axis, sin segment (`--c-sin`) draws on; cos stays visible; all objects stay | 2.5s | Both projections and both formulas visible, free exploration |

Scrubbing maps linearly to these step timelines; total timeline length = sum of step durations (about 15.5s). Any scrub position must render identically to playing to that position.

Per-step layer visibility is re-staged on step change. A step can set `keep` (default for angle theta) or `restage` (default for other params) per param (D-03).

### Hover/focus states
- Every interactive element has: hover (`--surface-raised`), pressed (scale 0.96), focus-visible (2px `--accent` ring, 2px offset), disabled (opacity 0.4, cursor not-allowed).
- The point is focusable (`tabindex=0`, `role="slider"`, `aria-label` from messages, `aria-valuetext` = current angle). Arrow-key rotation (1 degree, Shift = 15 degrees) is cheap and included now; full keyboard audit is Phase 6.

### Reduced motion
Out of audit scope until Phase 6, but tokens must make it a one-switch change: wrap all durations in `--dur-*` variables and the step animation engine accepts a `duration scale`. (`prefers-reduced-motion` sets scale to 0 for decorative effects.)

## Visual Primitives (stage) — D-10, D-11, D-12

Stage coordinate system: viewBox `-1.5 -1.5 3 3` (unit-circle radius 1 leaves 0.5 margin; y flipped so up is positive). Rendered square. Stroke widths use `vector-effect: non-scaling-stroke` in CSS px.

| Element | Style |
|---------|-------|
| Grid | Lines each 0.5 units, 1px `--grid`; shown only when axes exist (all steps from `intro`) |
| Axes | x and y lines 1.5px `--axis`; tick marks at +/-1 (length 8px) with labels "1", "-1" (Label 14px `--text-muted`) ; small arrowheads not drawn |
| Unit circle | 2px `--c-point`, fill none, outline opacity 0.9 |
| Radius line | 3px `--c-point`, from origin to point, round caps |
| Point | 20px circle `--c-point` fill, 2px ring `--bg`; halo per Interaction; sits above all layers |
| Angle arc | 3px `--c-angle`, radius 0.25 units, `--glow-sm`; label "theta" (KaTeX-like italic Greek via the same math font) at 0.38 units on the bisector, color `--c-angle` |
| Radian copies | 4px `--c-radian`, laid along the circle at radius 1 (slightly outside, 1.03) so they do not hide the circle; each copy has 2px end ticks; `--glow-sm` while animating |
| cos projection | 4px `--c-cos` along x-axis from origin to (cos theta, 0); dashed drop line 1.5px `--c-cos` at 60% opacity, dash 4 4, from the point to the x-axis; label "cos" Label 14px `--c-cos`, offset 12px below the segment midpoint (flips above when sin theta < 0) |
| sin projection | 4px `--c-sin` along y-axis from origin to (0, sin theta); dashed drop line 1.5px `--c-sin` 60% opacity; label "sin" Label 14px `--c-sin`, offset 12px left of the segment midpoint (flips right when cos theta < 0) |
| Labels | Never overlap the point or each other; labels are nudged out of the 36px point halo; text has a 3px `--bg` stroke (paint-order stroke) for legibility |
| Glow | `--glow-sm` on active/new strokes; removed 600ms after a step's animation ends except on the dragged point (`--glow-md` while hovered/dragged) |
| Draw-on | `stroke-dasharray`/`dashoffset` tween, `--ease-math` |

Edge cases to render correctly: theta = 0 (zero-length arc and projections are hidden, labels hidden), theta = 90 and 270 (cos segment length 0 hidden, readout shows `0` not `-0`), negative zero never displayed, labels flip sides at quadrant boundaries without jumping.

## Accessibility baseline (A11Y-01 now; A11Y-02..04 in Phase 6)

- Touch: all controls at least 44px; stage `touch-action: none`; no hover-only information (tooltips duplicate with `title`/aria-label; the "drag me" hint is visible without hover).
- The stage SVG has `role="img"` with an `aria-label` describing the step (from messages) and a `<title>`; the draggable point is the only focusable stage element.
- Caption region `aria-live="polite"`; readouts are not live-announced (avoid screen reader spam while dragging); `aria-valuetext` on the point slider updates on drag end.
- Color is never the sole carrier: labels "cos", "sin", "θ", "1 rad" sit on their elements (palette is color-blind-safe; remaining audit in Phase 6).
- `lang` attribute is set per locale; `<title>` and meta description translated.
