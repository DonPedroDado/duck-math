export const R_COPY = 1.03;                         // copies sit slightly outside the circle so they do not hide it

## Radian choreography (pr = radian-step local progress; E = easeMath)
| Copy j | Window on pr | Motion inside its window, q = seg(pr, a, b) |
|--------|--------------|---------------------------------------------|
| 0 (len 1) | [0, 0.42] | A q∈[0,0.25]: frame origin (0,0), heading `(π/6)·E(seg(q,0,0.25))`, k = 0 (peels up 30° off the x-axis). B q∈[0.25,0.6]: `b = E(seg(q,0.25,0.6))`, origin lerp (0,0)->(1,0), heading lerp π/6 -> π/2, k = 0 (moves to the edge, standing as a tangent). C q∈[0.6,1]: origin (1,0), heading π/2, `k = E(seg(q,0.6,1))` (bends onto the arc). opacity 1 |
| 1 (len 1) | [0.45, 0.62] | origin `(cos 1, sin 1)`, heading `1 + π/2`, opacity `E(seg(q,0,0.35))`, `k = E(seg(q,0.35,1))` |
| 2 (len 1) | [0.64, 0.81] | same with angle 2 |
| 3 (len π−3) | [0.83, 0.93] | same with angle 3 |
World point for local `(lx, ly)`: rotate by heading, add origin, multiply by `R_COPY`. Opacity multiplied by `1 − 0.6·dim` (40% in the radians step). `landed = q >= 1`. `endAngle = atan2` of the last point (normalized, 3 decimals). At pr = 0 there are no copies (continuous with the angle step); at pr = 1 all four are landed and the last ends at π. `oneRadLabel` (pr 0.42–0.52) and `piLabel` (0.93–1) come from `view`.
