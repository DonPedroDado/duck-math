<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser URL/query/hash -> redirect script | attacker can craft links to `/` with arbitrary query/hash |
| localStorage -> redirect script | value could be tampered by other same-origin script or user |
| messages/*.json -> build | translator-authored content compiled into the site |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-11 | Spoofing (open redirect) | scripts/postbuild.mjs redirect | mitigate | target path chosen from fixed allowlist `{en,de}`; query/hash only appended after a same-origin absolute path; e2e test with `?next=//evil.example` asserts origin unchanged |
| T-01-12 | Tampering | localStorage dm-locale | mitigate | value only used as allowlist key; unknown values ignored (e2e case `'xx'`) |
| T-01-13 | Tampering | message strings | accept | messages are authored in-repo and rendered as text by Svelte (escaped); no `{@html}` of message content |
| T-01-14 | Repudiation/Integrity | build pipeline | mitigate | prebuild parity check fails the build on missing/mismatched keys so no partially translated site ships |
</threat_model>
